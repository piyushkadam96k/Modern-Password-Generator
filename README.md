## ✨ Features
- 🌗 Dark & Light Mode  
- 🔒 Strong password generation using crypto-secure randomness  
- 📋 One-click copy  
- 🎨 Modern UI with smooth transitions  
- 🔁 Live updates as slider moves  
- 📱 Fully responsive

## 🚀 How to Use
1. Open `index.html`
2. Adjust sliders and toggles
3. Click **Generate Password**
4. Copy with one click
5. Switch themes anytime

## 🔐 Security
- Uses `crypto.getRandomValues` for secure randomness  
- 100% client-side  
- No data stored or sent anywhere

## 🧩 Tech Stack
- HTML5  
- CSS3  
- JavaScript
